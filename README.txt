WORK HOURS — FREE PERSONAL WEB APP

WHAT'S INCLUDED
- English-language monthly calendar and daily overtime/emergency entries.
- Multiple apartment jobs per day, editable/deletable entries.
- Monday–Sunday weekly report with separate Overtime and Emergency sections.
- Print / Save PDF using the phone or browser print dialog.
- Share plain-text report through the device's share sheet.
- Sent/Pending weekly report tracking.
- JSON backup and restore.
- Offline support after installation and first successful load.

HOW TO PUBLISH FOR FREE
1. Unzip this archive.
2. Upload the entire work-hours folder contents to a static HTTPS host (e.g. GitHub Pages or Cloudflare Pages).
3. Open the published HTTPS URL on your husband's phone.
4. iPhone: Safari > Share > Add to Home Screen. Android: Chrome > menu > Install app / Add to Home screen.
5. Enter his name, then tap a calendar day to add entries.
6. At the end of each week, use Save / Print PDF and Mark as Sent.
7. Download a backup regularly and store it in a safe place outside the browser.

IMPORTANT LIMITATIONS
- This first version stores all records only in that device/browser. It does not sync between devices.
- Clearing site data or uninstalling may remove the entries. Restore them from a downloaded backup.
- PDF is created via browser Print > Save as PDF, not through a dedicated PDF generator.
- The Share Report button shares formatted text, not a PDF attachment; save PDF first to attach a PDF.
- No account, cloud backend or paid subscription is needed.
